# 电商竞品矩阵框架
请对目标品类/单品与主要竞品做「电商货架维度」对标，而非泛行业对标：
1. **价格带与促销**：主流售价区间、折扣频率与力度、包邮门槛；
2. **标题/关键词覆盖**：核心词、长尾词、平台联想词覆盖差异（以 suggest 类检索结果为准）；
3. **评价与口碑**：评分分布、差评集中点、退货/售后投诉高发项；
4. **物流与履约**：发货时延、配送时效、退换政策；
5. **合规与准入**：认证/资质门槛（如 CE、FCC、CPC）、平台合规风险。

输出用对比矩阵表格（行=维度，列=我方/竞品 A/竞品 B），并给出「差异化切入点」与「须回避的劣势战场」。
所有价格、评分、销量类数字必须来自 retrieval_records；**不得把关键词热度、联想词排序当作销量或销售额**。
