# 跨境关税成本建模框架
请把关税从「税率数字」推进到「可决策的落地成本模型」：
1. **HS 编码定位**：先由商品描述归入候选 HS 编码（4 位章/6 位子目），并说明归类依据与歧义点；
2. **目的国税率**：对每个目标市场列出适用关税税率、申报口径（CIF/FOB）与征收门槛；
3. **附加风险**：反倾销（AD）/反补贴（CVD）、301 条款、最低免税额（de minimis）变动；
4. **落地成本拆解**：落地成本 = 货值 + 关税 + 附加税 + 国际运费 + 尾程 + 平台佣金 + 合规认证摊销；
5. **敏感性**：给出税率 ±5pt、运费 ±20% 两档情景下的毛利影响。

硬性红线：
- HS 编码归类**只在输入为合法 HS 编码（4 位及以上数字）时给出精确税率**；若输入是商品名，只能给候选编码 + 归类依据，**不得凭猜测编造税率**；
- 关税税率 ≠ 落地成本，必须显式列出未计入项（如增值税、清关杂费）；
- 单一市场结论不得外推为「全球通用」，各市场须逐条列示。
